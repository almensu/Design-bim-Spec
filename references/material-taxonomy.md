# Material Taxonomy v0.1

This is the authoritative material classification reference.

## Classification rule

Classify by **communication function + medium + layout behavior**, not dimensions alone.

If evidence is insufficient, use `unknown`. Do not invent a new canonical type during execution.

## ecommerce_marketing

### ecommerce_main_image
Typical ratios: 1:1, 3:4.

Purpose:
- immediate product recognition;
- one dominant selling proposition;
- conversion support.

Common semantic zones:
- background;
- hero product;
- headline/value proposition;
- offer/price;
- CTA/purchase cue;
- proof/brand.

### pdp_hero
Purpose:
- establish product value on first screen;
- lead into purchase journey.

Common zones:
- hero visual;
- main proposition;
- supporting proposition;
- price/offer;
- CTA;
- proof/trust.

### livestream_background
Purpose:
- support a live presenter while preserving commercial information.

Common zones:
- presenter-safe zone;
- product/offer zone;
- brand zone;
- persistent price/promotion;
- CTA/instruction zone.

### feed_ad
Typical ratio: 9:16.

Purpose:
- arrest attention quickly;
- communicate one main benefit;
- drive action.

Common zones:
- hook;
- product/scene;
- claim/proof;
- offer;
- CTA.

## offline_marketing

### dm_leaflet_or_fold
Purpose:
- compact offline communication;
- support a local or in-person decision.

Common zones:
- cover hook;
- offer;
- service/product blocks;
- proof;
- contact/QR;
- footer/legal.

### marketing_poster
Typical ratios: 4:3, 16:9, plus print-specific ratios when evidenced.

Purpose:
- distance readability;
- dominant first fixation;
- essential message retention.

Common zones:
- dominant visual;
- headline;
- date/time/offer;
- supporting copy;
- CTA/contact.

### flyer
Purpose:
- balance visual attraction and compact information density.

Common zones:
- headline;
- hero visual;
- benefits;
- offer;
- contact/CTA;
- QR/proof.

## unknown

Use when:
- context is cropped;
- the material belongs to an unsupported family;
- evidence does not distinguish neighboring types.

Return:
- nearest structural traits;
- likely medium;
- missing evidence;
- confidence.

## Classification evidence

Useful evidence includes:
- aspect ratio;
- presence of CTA;
- presenter-safe region;
- print margins;
- QR/contact density;
- product dominance;
- information density;
- viewing distance;
- persistent promotional zones.

Dimensions are evidence, not the classifier by themselves.
